# ♟️ Chess Clock

A simple, interactive chess clock web application designed to manage time during chess games. Players can start, pause, and switch between two timers with a clean and responsive interface.

## 🌐 Live Demo

[Play Chess Clock](https://user-fiero.github.io/chess-clock/)

## ✨ Features

- Two independent timers for White and Black.
- Start and pause game functionality.
- Switch turns between players.
- Real-time countdown display.
- Clean and user-friendly interface.
- Responsive design for different screen sizes.
- Reset functionality to start a new game.

## 🛠️ Technologies Used

- **HTML5** – Application structure.
- **CSS3** – Styling and responsive layout.
- **JavaScript** – Timer logic and game interactions.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/user-fiero/chess-clock.git
```

### 2. Navigate to the project directory

```bash
cd chess-clock
```

### 3. Run the application

Open `index.html` in your web browser.

No additional dependencies or installations are required.
