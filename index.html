How to Play

Starting the Game

Player with black pieces clicks opponent's clock to start the game.

Keyboard Controls

Left player can use following keys:

1, 2, 3, q, w, e, a, s, d, spacebar, Enter

Right player can use following keys:

8, 9, 0, i, o, p, k, l, ;, spacebar, Enter

Game Rules

• Click opponent's clock when you finish your move

• Clock turns red when time is low (under 30 seconds)

• Sound alerts at 30s, 10s, and game over

• Pause button to pause/resume

• Reset button to restart

• Move counter tracks total moves
